Conexión con GitHub

Los datos se guardan como archivos JSON en tu propio repositorio de GitHub, así todos en FyF ven la misma información. Cada persona conecta su propio token en su navegador — no se comparte con nadie más.

Cómo generar el token (una sola vez, por persona):
1. Andá a github.com/settings/personal-access-tokens/new
2. En "Repository access" elegí Only select repositories y seleccioná este repo.
3. En "Permissions → Repository permissions" poné Contents: Read and write.
4. Generá el token y pegalo acá arriba (empieza con github_pat_).
